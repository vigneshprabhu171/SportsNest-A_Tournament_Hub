# SportsNest

A modern full-stack sports tournament management platform with React, Tailwind CSS, Express, MongoDB, JWT auth, and role-based dashboards for players, organizers, and admins.

## Quick Start

1. Copy `.env.example` to `.env` and update values.
2. Install dependencies with `npm install`.
3. Start MongoDB locally or update `MONGO_URI`.
4. Run `npm run seed` to create demo data and the admin account.
5. Run `npm run dev`.

Default admin seed credentials come from `.env`:

- Email: `admin@sportsnest.local`
- Password: `Admin@12345`
